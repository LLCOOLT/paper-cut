# tools/port/interp_audit_check.py: what a frame drawn between the game's own may leave changed (the audit's "net"
# sites, port/src/aurora/interp_audit.c). One key a line ("writer FUNCTION (file.c)" or "global NAME"), "*" for any
# run of characters. Each is a cache or draw state the game's next frame computes again before anything reads it.
# Anything else is a draw that changes the game: fix it (docs/FRAME_INTERPOLATION.md), don't list it here.

writer winRootBgCaptureDisp (win_root.c)               # the same backdrop's "captured" flag

writer offscreenAddBoundingBox (offscreendrv.c)        # their screen boxes, measured in the draw
writer `anonymous namespace'::init_texobj_common (*)   # Aurora's GXTexObj init for those copies
writer effFlameDisp (eff_flame_n64.c)                  # the flame's vertices, transformed in its draw
writer effPokopiThunderDisp (eff_pokopi_thunder_n64.c) # the bolt's points, from its table and frame
writer select_disp3* (winmgr.c)                        # an item or partner list's help text, looked up each draw
writer menuDisp (title_menu_aurora.c)                  # the port's title menu's resolution label
writer animPoseMain (animdrv.c)                       # the shared float scratch (useFloatScratch); each pose draw fills it
# --- heap: the in-between frame's own work (interp_aurora.c puts the list back as the game left it)
writer dispEntry (dispdrv.c)                          # the letterbox entries past the list's end (portCamLetterBoxInBetween)
writer qqsort (system.c)                              # the draw list's sort work
