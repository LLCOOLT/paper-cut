A pack names each texture by its size, format and a hash of its pixels and palette, as Dolphin does. Two files with one name replace the same texture, and only one is used: between mods, the one higher in the list; the mods before the textures folder; inside one folder, either, so keep one. Textures with the same pixels share a name, so one file replaces them all; a name with $ for a hash covers every texture it stands for.
Un pack nomme chaque texture d'après sa taille, son format et un hachage de ses pixels et de sa palette, comme Dolphin. Deux fichiers portant un même nom remplacent la même texture, et un seul est utilisé : entre mods, celui qui est plus haut dans la liste ; les mods avant le dossier des textures ; dans un même dossier, l'un ou l'autre, donc gardez-en un. What is shuffled
Ce qui est mélangé

Key items, partners, the curses, hammer and boots move too, placed by the TTYD apworld's logic so the Shadow Queen can always be reached. That logic is the TTYD AP mod's open world (chapters open by items, not the story), so the mod must be installed as a code mod (Mods tab, docs/MODDING.md); without it the game can't be finished. Badges, items or Star Pieces must be shuffled too.
Les objets clés, les partenaires, les malédictions, le marteau et les bottes bougent aussi, placés par la logique de l'apworld de TTYD pour que la Reine des Ténèbres soit toujours atteignable. Cette logique est le monde ouvert du mod AP de TTYD (les chapitres s'ouvrent par des objets, pas par l'histoire), donc le mod doit être installé comme mod de code (onglet Mods, docs/MODDING.md) ; sans lui, le jeu ne peut pas être terminé. Les badges, les objets ou les Morceaux d'étoile doivent aussi être mélangés.

Without key items the story is the game's own: only things the story never asks for move (badges, items nothing needs, Star Pieces, Shine Sprites, in the places the game hands them out itself), so every seed can be finished. No mod needed.
Sans objets clés, l'histoire est celle du jeu : seules bougent les choses que l'histoire ne demande jamais (badges, objets dont rien n'a besoin, Morceaux d'étoile, Soleils, aux endroits où le jeu les donne lui-même), donc chaque graine peut être terminée. Aucun mod nécessaire.

At the start, to the randomizer folder in the user folder (spoiler_<seed>.txt): where every item went and, for the open world, the order the logic expects key items to be found in.
Au lancement, dans le dossier randomizer du dossier utilisateur (spoiler_<graine>.txt) : où chaque objet est allé et, pour le monde ouvert, l'ordre dans lequel la logique s'attend à trouver les objets clés.
