# photo-mode, the Start menu's Settings tab in the JP release's font: see tools/port/gen_lang.py

Photo mode
フォトモード

Closes the menu and holds the game: the sticks move the camera, {SOUTH:Return} takes a picture, {NORTH:H} hides the HUD, {EAST:Escape} goes back.
