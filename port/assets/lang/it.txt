A pack names each texture by its size, format and a hash of its pixels and palette, as Dolphin does. Two files with one name replace the same texture, and only one is used: between mods, the one higher in the list; the mods before the textures folder; inside one folder, either, so keep one. Textures with the same pixels share a name, so one file replaces them all; a name with $ for a hash covers every texture it stands for.
Un pacchetto nomina ogni texture in base alla sua dimensione, al formato e a un hash dei suoi pixel e della palette, come Dolphin. Due file con lo stesso nome sostituiscono la stessa texture, e ne viene usato uno solo: tra le mod, quella più in alto nella lista; le mod prima della cartella delle texture; dentro una cartella, uno qualsiasi, quindi tienine uno. Le texture con gli stessi pixel condividono un nome, così un file le sostituisce tutte; un nome con $ al posto di un hash copre ogni texture che rappresenta.

What is shuffled
Cosa viene mescolato

Key items, partners, the curses, hammer and boots move too, placed by the TTYD apworld's logic so the Shadow Queen can always be reached. That logic is the TTYD AP mod's open world (chapters open by items, not the story), so the mod must be installed as a code mod (Mods tab, docs/MODDING.md); without it the game can't be finished. Badges, items or Star Pieces must be shuffled too.
Anche gli strumenti, i compagni, le maledizioni, il martello e gli stivali si spostano, piazzati dalla logica dell'apworld di TTYD perché la Regina Ombra sia sempre raggiungibile. Quella logica è il mondo aperto della mod AP di TTYD (i capitoli si aprono con oggetti, non con la storia), quindi la mod deve essere installata come mod di codice (scheda Mod, docs/MODDING.md); senza di essa il gioco non si può finire. Anche tessere, oggetti o Scheggiastelle devono essere mescolati.

Without key items the story is the game's own: only things the story never asks for move (badges, items nothing needs, Star Pieces, Shine Sprites, in the places the game hands them out itself), so every seed can be finished. No mod needed.
Senza strumenti la storia è quella del gioco: si spostano solo cose che la storia non chiede mai (tessere, oggetti che non servono a nulla, Scheggiastelle, Soli Custodi, nei posti dove il gioco stesso li dà), così ogni seme si può finire. Nessuna mod necessaria.

At the start, to the randomizer folder in the user folder (spoiler_<seed>.txt): where every item went and, for the open world, the order the logic expects key items to be found in.
All'avvio, nella cartella randomizer della cartella utente (spoiler_<seme>.txt): dove è finito ogni oggetto e, per il mondo aperto, l'ordine in cui la logica si aspetta di trovare gli strumenti.
