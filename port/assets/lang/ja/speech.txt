# speech: see tools/port/gen_lang.py

Read text aloud
テキストの読み上げ

The system's voice reads the message windows as each page shows, and with "and menus" the Start menu's help, the Settings tab, the battle menus and the game's lists as you move through them. In the game's language when the system has a voice for it.
システムの音声が、メッセージをページごとに読み上げます。「メニューも」では、スタートメニューのヘルプ、設定タブ、バトルメニュー、ゲームのリストもカーソルの移動に合わせて読み上げます。システムにその言語の音声があれば、ゲームの言語で読みます。
