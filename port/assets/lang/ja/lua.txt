# Lua mods (port/mods/lua_host.cpp, port/settings/features/lua_console.cpp, mods_manager.cpp), in Japanese: an English line, then its translation, then a blank line.

Lua mods
Luaモッド

Mods with a lua folder run Lua scripts (docs/LUA_MODDING.md): each in a sandbox of its own, with no file or network access. A folder mod starts again by itself when its Lua files change. Online, they run only when both players have the same Lua mods.
luaフォルダのあるモッドはLuaスクリプトを実行します（docs/LUA_MODDING.md）。それぞれ専用のサンドボックスで動き、ファイルやネットワークには触れません。フォルダのモッドはLuaファイルが変わると自動で再起動します。オンラインでは両方のプレイヤーが同じLuaモッドを入れているときだけ動きます。
