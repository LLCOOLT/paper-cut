Lua mods
Mods Lua

Mods with a lua folder run Lua scripts (docs/LUA_MODDING.md): each in a sandbox of its own, with no file or network access. A folder mod starts again by itself when its Lua files change. Online, they run only when both players have the same Lua mods.
Les mods avec un dossier lua exécutent des scripts Lua (docs/LUA_MODDING.md) : chacun dans son propre bac à sable, sans accès aux fichiers ni au réseau. Un mod en dossier redémarre tout seul quand ses fichiers Lua changent. En ligne, ils ne tournent que si les deux joueurs ont les mêmes mods Lua.
