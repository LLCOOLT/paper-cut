Game text packs
Packs de texte du jeu

A text pack changes the game's own messages (dialogue, names, items, menus) in any language: a mod with a messages folder. This writes every message of your disc into the mods folder as a pack's starting point; see docs/DELOCALIZATION.md.
Un pack de texte change les textes du jeu lui-même (dialogues, noms, objets, menus) dans n'importe quelle langue : un mod avec un dossier messages. Ceci écrit chaque texte de votre disque dans le dossier des mods comme point de départ d'un pack ; voir docs/DELOCALIZATION.md.

Start the game to write the template: it reads the messages from your disc.
Lancez le jeu pour écrire le modèle : il lit les textes sur votre disque.
