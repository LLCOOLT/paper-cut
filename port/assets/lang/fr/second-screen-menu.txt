# The second screen's Start menu (port/include/port/companion_menu.h, port/settings/features/companion.cpp)

On a device with a second screen of its own (a dual-screen handheld): the Start menu there, live while you play.
Sur un appareil doté de son propre second écran (une console portable à double écran) : le menu Start dessus, en direct pendant que vous jouez.
