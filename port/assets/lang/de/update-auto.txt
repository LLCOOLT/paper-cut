# Install updates automatically (port/settings/features/update_check.cpp): see tools/port/gen_lang.py

Install updates automatically
Updates automatisch installieren

A new version found at start downloads in the background, is checked, and is put in place the next time the game starts. Never while playing online.
Eine beim Start gefundene neue Version wird im Hintergrund geladen, geprüft und beim nächsten Spielstart eingesetzt. Nie beim Online-Spiel.
