# Install updates automatically (port/settings/features/update_check.cpp): see tools/port/gen_lang.py

Install updates automatically
Updates automatisch installieren

A new version found at start is downloaded in the background, checked against the release's checksum, and put in place the next time the game starts. Never during online play or a replay.
Eine beim Start gefundene neue Version wird im Hintergrund heruntergeladen, mit der Prüfsumme der Veröffentlichung verglichen und beim nächsten Spielstart eingesetzt. Nie während Online-Spielen oder einer Wiederholung.
