Keep every save file
Jeden Spielstand behalten

Each save the game writes is also kept in the library below, with a picture of where it was made, so there is no limit of four files.
Jeder Spielstand, den das Spiel schreibt, wird auch in der Bibliothek unten behalten, mit einem Bild vom Ort des Speicherns: keine Grenze von vier Dateien mehr.

Settings per save file
Einstellungen pro Spielstand

The difficulty, the Enhancements and the challenge rules are saved with each file and come back when it is loaded. Display, sound and controls stay the same for every file.
Schwierigkeit, Verbesserungen und Herausforderungsregeln werden mit jeder Datei gespeichert und kehren beim Laden zurück. Bild, Ton und Steuerung bleiben für alle Dateien gleich.
