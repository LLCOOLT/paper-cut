Lua mods
Lua-Mods

Mods with a lua folder run Lua scripts (docs/LUA_MODDING.md): each in a sandbox of its own, with no file or network access. A folder mod starts again by itself when its Lua files change. Online, they run only when both players have the same Lua mods.
Mods mit einem lua-Ordner führen Lua-Skripte aus (docs/LUA_MODDING.md): jedes in einer eigenen Sandbox, ohne Zugriff auf Dateien oder das Netzwerk. Ein Ordner-Mod startet von selbst neu, wenn sich seine Lua-Dateien ändern. Online laufen sie nur, wenn beide Spieler dieselben Lua-Mods haben.
