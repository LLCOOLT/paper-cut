A pack names each texture by its size, format and a hash of its pixels and palette, as Dolphin does. Two files with one name replace the same texture, and only one is used: between mods, the one higher in the list; the mods before the textures folder; inside one folder, either, so keep one. Textures with the same pixels share a name, so one file replaces them all; a name with $ for a hash covers every texture it stands for.
パックはDolphinと同じく、サイズ、形式、ピクセルとパレットのハッシュで各テクスチャに名前をつけます。同じ名前の2つのファイルは同じテクスチャを置きかえ、使われるのは1つだけです：MOD同士ならリストで上にある方、texturesフォルダーよりMOD、1つのフォルダーの中ならどちらか（なので1つだけ残してください）。ピクセルが同じテクスチャは名前も同じなので、1つのファイルで全部置きかわります。ハッシュの代わりに$を使った名前は、それが表すすべてのテクスチャに使われます。
