Shuffles the game's items among their places from a seed, with no Archipelago server: turn it on, pick the seed and what moves, then start the game and begin a new file. The same seed and choices always give the same game, so a seed can be shared.
Baraja los objetos del juego entre sus lugares a partir de una semilla, sin servidor de Archipelago: actívalo, elige la semilla y lo que se mueve, luego inicia el juego y empieza un archivo nuevo. La misma semilla y las mismas opciones dan siempre la misma partida, así que una semilla se puede compartir.

What is shuffled
Lo que se baraja

Key items, partners, the curses, hammer and boots move too, placed by the TTYD apworld's logic so the Shadow Queen can always be reached. That logic is the TTYD AP mod's open world (chapters open by items, not the story), so the mod must be installed as a code mod (Mods tab, docs/MODDING.md); without it the game can't be finished. Badges, items or Star Pieces must be shuffled too.
Los objetos clave, los compañeros, las maldiciones, el martillo y las botas también se mueven, colocados por la lógica del apworld de TTYD para que siempre se pueda llegar a la Reina de las Sombras. Esa lógica es el mundo abierto del mod AP de TTYD (los capítulos se abren con objetos, no con la historia), así que el mod debe instalarse como mod de código (pestaña Mods, docs/MODDING.md); sin él, el juego no se puede terminar. También hay que barajar medallas, objetos o Piezas Estrella.

Without key items the story is the game's own: only things the story never asks for move (badges, items nothing needs, Star Pieces, Shine Sprites, in the places the game hands them out itself), so every seed can be finished. No mod needed.
Sin objetos clave la historia es la del juego: solo se mueven cosas que la historia nunca pide (medallas, objetos que nada necesita, Piezas Estrella, Soles, en los lugares donde el propio juego los entrega), así que toda semilla se puede terminar. No hace falta ningún mod.

At the start, to the randomizer folder in the user folder (spoiler_<seed>.txt): where every item went and, for the open world, the order the logic expects key items to be found in.
Al inicio, en la carpeta randomizer de la carpeta de usuario (spoiler_<semilla>.txt): adónde fue cada objeto y, para el mundo abierto, el orden en que la lógica espera encontrar los objetos clave.
