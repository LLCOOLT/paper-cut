Keep every save file
Conserva ogni salvataggio

Each save the game writes is also kept in the library below, with a picture of where it was made, so there is no limit of four files.
Ogni salvataggio scritto dal gioco viene conservato anche nella libreria qui sotto, con un'immagine del luogo in cui è stato fatto: niente più limite di quattro file.

Settings per save file
Impostazioni per salvataggio

The difficulty, the Enhancements and the challenge rules are saved with each file and come back when it is loaded. Display, sound and controls stay the same for every file.
La difficoltà, i Miglioramenti e le regole delle sfide vengono salvati con ogni file e tornano quando lo carichi. Schermo, audio e comandi restano uguali per tutti i file.
