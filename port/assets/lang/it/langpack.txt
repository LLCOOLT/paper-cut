# language packs: see tools/port/gen_lang.py

Language packs
Pacchetti di lingua

A language pack translates Paper Cut's own menus: a folder in the mods folder holding a lang folder of text files. It adds a language to Menu language, or changes the texts of one that is there.
Un pacchetto di lingua traduce i menu di Paper Cut: una cartella nella cartella delle mod con dentro una cartella lang di file di testo. Aggiunge una lingua a Lingua dei menu, o cambia i testi di una che c'è già.
