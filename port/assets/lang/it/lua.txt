Lua mods
Mod Lua

Mods with a lua folder run Lua scripts (docs/LUA_MODDING.md): each in a sandbox of its own, with no file or network access. A folder mod starts again by itself when its Lua files change. Online, they run only when both players have the same Lua mods.
Le mod con una cartella lua eseguono script Lua (docs/LUA_MODDING.md): ognuna in una sandbox tutta sua, senza accesso ai file né alla rete. Una mod in cartella riparte da sola quando i suoi file Lua cambiano. Online funzionano solo se entrambi i giocatori hanno le stesse mod Lua.
