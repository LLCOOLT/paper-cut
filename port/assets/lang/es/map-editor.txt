# map-editor: see tools/port/gen_lang.py

Map editor
Editor de mapas

Place pipes, blocks, switches, signs, items, NPCs and loading zones in the room Mario is in, from the game's own models; move them, test them, and save them as a mod in your mods folder (maps/<room>.json), which the mod manager then lists. Mouse: click to place or pick, drag to move, right-drag to look; WASD and Q / E fly; Tab test play; Esc closes and saves.
Coloca tuberías, bloques, interruptores, carteles, objetos, PNJ y zonas de paso en la sala donde está Mario, con los modelos del juego; muévelos, pruébalos y guárdalos como un mod en tu carpeta de mods (maps/<room>.json), que el gestor de mods mostrará. Ratón: clic para colocar o elegir, arrastrar para mover, arrastrar con el derecho para mirar; WASD y Q / E para volar; Tab para probar; Esc cierra y guarda.
