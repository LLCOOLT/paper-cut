# Paper Cut 0.3.0: the plan

**0.3.0 is Super Luigi: the stories, playable.** The user decided this on 2026-11-02. See `docs/super_luigi/HANDOFF.md` for where it stands.

**Versions:** Super Luigi ships for US first, marked "US only for now". JP and EU keep building and running, with fallback art and little testing of the mode, and get proper support in a later update.

**Platforms:** Windows, macOS, Linux, iOS and Android, as 0.2.0's features do.

## Moved to 0.4.0

The user chose these on 2026-11-01, on the ideas page: https://claude.ai/artifact/8e3fbQ8dThUQrpVZobyLv9 (sizes: S, M, L). None has started. Each must work on all five platforms and all three versions, except that HDR needs a display and system that support it, and a second player needs a second controller (on phones, a paired one).

| Idea | Size |
|---|---|
| Built-in randomizer | L |
| Challenge presets | M |
| Boss refights | M |
| Autosave at room changes | S |
| Second player drives the partner | M |
| Button prompts that match your controller | M |
| HDR output | M |
| Mod browser | L |
| Character export and import for modders | M |
| Decomp sync as a routine | M |

A good start for 0.4.0 is the small and medium ones that don't touch Super Luigi's files: autosave, challenge presets, controller prompts and the decomp sync.

## Dropped

Don't pick these up unless asked:
- missing release-build characters;
- a faster warm-up;
- deterministic captures;
- tou_03 at 120 Hz;
- EU sweeps;
- trying the untried features;
- polishing the story poses;
- photo mode;
- read dialogue aloud;
- hold instead of mash;
- less shake and flash;
- rewind;
- Discord presence;
- an AltStore source;
- in-app updates;
- CI that fits the budget.
