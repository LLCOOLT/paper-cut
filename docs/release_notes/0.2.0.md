The port is now **Paper Cut**: one app that plays the Japanese (G8MJ01), US (G8ME01) and, new in this release, European (G8MP01) versions of Paper Mario: The Thousand-Year Door, from the game's C decompilation, with no emulator.

**Downloads**

| | |
|---|---|
| Windows (x64) | `papercut-0.2.0-windows-x64.zip` |
| macOS (Apple silicon) | `papercut-0.2.0-macos-arm64.zip` |
| Linux (x86-64) | `papercut-0.2.0-linux-x64.zip` (glibc 2.39 or newer: Ubuntu 24.04, Fedora 40, Debian 13 and later) |
| iOS and iPadOS | `papercut-0.2.0-<us\|jp\|eu>-ios-unsigned.ipa` (unsigned: install with AltStore, SideStore or Sideloadly) |
| Android (arm64) | `papercut-0.2.0-<us\|jp\|eu>-android-arm64.apk` (debug-signed; not yet tested on a device) |

On a computer, one download plays every version. A phone app can only run its own code, so phones have one app per version.

**What's new**
- **The launcher:** a library of your discs, each recognised by version, with Play, quick resume ("Continue" picks up where you left off, even after a crash or a closed app) and the settings, before the game starts. Mouse, keyboard, controller or touch.
- **The European version**, in English, German, French, Spanish or Italian, at 50 or 60 Hz. Any version can also show the text of another disc you own.
- **Settings, redone:** tabs, a search box, and a mark on every option that changes how the game plays or what it saves. Keyboard keys can be changed (WASD or the arrows move by default).
- **Play as Luigi:** Luigi in Mario's place, with 156 animations of his own made for Paper Cut. Mario takes Luigi's place in the story's scenes, and the text, menus and credits swap the brothers' names.
- **Gameplay+** (all off by default): partner quick-swap, faster menus and text, skipped repeated scenes, Save Blocks without the question, storage at any Save Block, a bigger bag, badge loadouts, faster walking, coin and Star Point multipliers, retry on Game Over, fast travel, a collectibles journal, a jukebox, free Tattle, battle pop-ups, Pit and Glitz Pit tweaks, a remake-style balance, and New Game+.
- **Accessibility:** a difficulty slider and action-command assist.
- **Practice:** a speedrun timer with load removal and LiveSplit, frame advance, RNG control, stat, item and story-flag editors, a memory watch, ten labelled save-state slots, and 25 achievements.
- **Display:** 4:3 to 32:9, HUD size, supersampling, anisotropic filtering, MSAA, sharp text, CRT, paper-grain and sharpen filters, variable refresh rate and a performance overlay.
- **Audio and input:** music, effects and ambience volumes; the mouse in the game's menus, lists and battle commands.
- **Saves:** automatic backups, conversion between versions, and iCloud on Apple devices.
- **Mods:** a mod manager, hooks generated from the decompilation, a texture-pack workflow, audience effects from chat, a boss rush and an endless Glitz Pit.
- **Phones and tablets:** the launcher by touch, landscape first, and a settings button on the touch controls.
- **Preparing graphics:** on the first start, the graphics the game needs are built before it begins (any button skips it).

**You need your own copy of the game:** a disc image (`.iso`, `.rvz`, `.gcm`...). Add it in the launcher.

**Known issues**
- In some scenes a character may not appear on the first visit (the guards in Rogueport's square, for one). Waiting lets the scene continue.
- The European version's battles and story haven't been swept as thoroughly as the Japanese and US ones; every map boots on all three.
- The Glitz Pit screen (tou_03) differs slightly at 120 Hz compared with 60.
- Nothing is code-signed. Windows SmartScreen warns on first run (More info > Run anyway). On macOS, the first time it's blocked: try to open it, then System Settings > Privacy & Security > Open Anyway. The iOS app must be signed by a sideloading tool.
- Linux has been tested headless only, and the Android APKs haven't been run on a device yet.
