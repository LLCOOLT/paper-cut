The first release of the native port of Paper Mario: The Thousand-Year Door, for the Japanese (G8MJ01) and US (G8ME01) versions. It's built from the game's C decompilation, with no emulator.

**Downloads**

| | |
|---|---|
| Windows (x64) | `ttyd-port-0.1.0-us-windows-x64.zip`, `ttyd-port-0.1.0-jp-windows-x64.zip` |
| macOS (Apple silicon) | `ttyd-port-0.1.0-us-macos-arm64.zip`, `ttyd-port-0.1.0-jp-macos-arm64.zip` |
| Linux (x86-64) | `ttyd-port-0.1.0-us-linux-x64.zip`, `ttyd-port-0.1.0-jp-linux-x64.zip` (glibc 2.39 or newer: Ubuntu 24.04, Fedora 40, Debian 13 and later) |
| iOS and iPadOS | `ttyd-port-0.1.0-us-ios-unsigned.ipa`, `ttyd-port-0.1.0-jp-ios-unsigned.ipa` (unsigned: install with AltStore, SideStore or Sideloadly) |
| Android (arm64) | `ttyd-port-0.1.0-us-android-arm64.apk`, `ttyd-port-0.1.0-jp-android-arm64.apk` (debug-signed; not yet tested on a device) |

Intel Macs and arm64 Linux are built from source for now (see the README).

**What's in it**
- The whole game: every map and battle of both versions boots and runs, the story plays through, and memory card saves work with Dolphin's `.gci` files.
- **120 Hz and up:** frames drawn between the game's own 60, with the game's logic untouched.
- **16:9** widescreen, any window size, internal resolution up to 8×, anti-aliasing and display options.
- **Settings page** (F1, Back/Select, or a three-finger tap): video, audio, controls (rumble, remapping, touch controls), gameplay (fast-forward, text and run speed, skip intro, an action-command cue), save warps.
- **Save states:** four slots, F5 and F8.
- **Mods:** a mods folder and a Mods tab. Mods can replace or add disc files, textures and text (Dolphin texture packs work as they are), change the game's item, attack and unit data by name, run scripts in the game's own script language (new maps too), and run code with hooks on 61 of the game's functions. Tools port GameCube code mods built on ttyd-tools to the PC from their source. Four example mods are in the zip; see `docs/MODDING.md`.
- **Archipelago** (US): a TTYD multiworld seed applied without patching a disc image, and a built-in client for the server. Choose the `.apttyd` seed and the server on the settings page's Archipelago tab. Playing one also needs the randomizer's game-side mod (TTYD AP), which is GPL and not included: build it as a code mod from its source with the porting tools.
- **Phones and tablets** (iOS, iPadOS and Android): on-screen controls, portrait or landscape, haptics.

**You need your own copy of the game:** a disc image of the matching version (`.iso`, `.rvz`, `.gcm`...). The game asks for it on first start.

**Known limits:**
- Nothing is code-signed. Windows SmartScreen warns on first run (More info > Run anyway). On macOS, right-click the app > Open the first time. The iOS app must be signed by a sideloading tool, and a free Apple ID signs it for 7 days at a time.
- A few maps differ slightly at 120 Hz compared with 60.
- The Linux build is tested headless in CI (every map, saves) but hasn't been played on a Linux desktop yet. The Android APKs haven't been run on a device yet.
