# raw2struct.py type map: which raw `s32 name[] = {...}` tables are which struct.
#
#   <name regex (full match)>  <path regex or *>  <C type>  <header that declares it>
#
# First matching line wins. The table is always emitted as an array (`Type name[]`), so the
# name keeps decaying to a pointer exactly like the raw s32 array did. A table whose byte size is
# not a multiple of sizeof(type), or whose words don't fit the fields (pointer in an integer
# field, symbolic word split into bytes, nonzero padding), is reported and left unconverted.
# A type containing `*` (e.g. `const char*`) makes a plain pointer list.
#
# How each type was chosen (consumer):
#   BeroEntry          evt_bero_get_info (src/event/evt_bero.c) walks bero tables via BeroEntry*
#   NpcSetupInfo       evt_npc_setup (src/event/evt_npc.c)
#   BattleUnitSetup    BtlUnit_Entry / BattleGroupSetup.enemyData (btlparty_*, entry_*)
#   BattleGroupSetup   NpcBattleSelect.groupSetup (btlgrp_*)
#   NpcBattleSelect    NpcSetupBattleInfo.select/altSelect (btlgrpsel_*), weight 0 terminates
#   BattleUnitKind     BattleUnitSetup.mUnitKindParams (unit_*), 0xC4 bytes
#   BattleUnitKindPart BattleUnitKind.mParts (parts*)
#   BattleDataEntry    BattleUnitKind.dataTable (data_table*), {0, NULL} terminates
#   BattleWeapon       btlevtcmd_* weapon arguments (weapon_*), 0xC0 bytes
#   PoseTableEntry     BattleUnitKindPart.poseTable (pose_table*)
#   BtlPoseSoundData   btlevtcmd_AnimeSetPoseSoundTable -> BtlUnit_PoseSoundInit (battle_unit.c)
#   HitDamageReturn    evt_hit_damage_return_set (src/event/evt_hit.c), NULL name terminates
#   DoorData           door_entry / evt_door_param / npc_hide_onoff (src/event/evt_door.c)
#   const char*        DoorData.npcs/mobjs/items name lists, NULL terminated
